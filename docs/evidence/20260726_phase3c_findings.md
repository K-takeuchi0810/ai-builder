# 証跡: Phase 3c セグメント別重み探索の結論 (2026-07-26)

ユーザーの本題「季節・馬場・コース等の条件別に、どの重み付けで印を打つと的中率/回収率が良いか」を
**初めて正面から検証**した結果。生データ: `20260722_phase3c_segment_search.json`。

## 実施規模 (範囲を狭めていない)

- **候補 119,069 通り**の重み付け (速度実測して2.5h予算いっぱいに自動設定)
- **全8粒度**: 場×芝ダ×距離×馬場 (427セグ) 〜 全体 まで階層的に
- **全3目的関数**: 勝率 / 複勝率 / 単勝回収率
- 評価は **◎(スコア1位) ベース** = 「印を打った時」の成績
- 全6年 (2021-2026, 19,215レース) × 167特徴量
- 厳格ガード: TRAIN探索 → **VALID選択** → **TEST(2025)と2026の両方で再現** かつ
  **①その条件の1番人気 ②全体最適重み の両方を超える** ことを採用条件に

| 目的関数 | 評価可(セグメント数) | 採用 |
|---|---|---|

- **ユーザーが例示した粒度 (場×芝ダ×距離×馬場, 427セグ・評価可78) は採用ゼロ。**

## 決定的診断: 採用3件はすべて「万馬券まぐれ当たり」

採用された3件の中身 (◎の的中率と回収率を並べると正体が分かる):

| セグメント | 目的 | TEST勝率 | 人気の勝率 | TEST回収率 | 2026回収率(n) |
|---|---|---|---|---|---|
| 中京ダ・マイル | roi | **8.0%** | 33.3% | **0.955** (<1) | 5.277 (n=22) |
| 障害・長距離・良 | roi | **7.4%** | 34.7% | 1.643 | 1.181 (n=43) |
| ダート・マイル | roi | **2.6%** | 35.0% | **0.864** (<1) | 0.998 (n=631) |

1. **◎の的中率が壊滅的**(2.6〜8.0% 対 人気33〜35%)。つまりこれらは「強い馬」ではなく
   **大穴を選ぶ重み付け**。回収率はごく稀な高配当だけで作られている。
2. **VALIDの回収率が異常値** (5.281 / 4.320 / 1.822)。126レースで回収率528%は、
   エッジではなく**1〜2本の万馬券**。119,069候補から最大値を選べば、
   「その年たまたま爆弾を拾った重み」が必ず選ばれる (winner's curse)。
3. **3件中2件は TEST で回収率 < 1.0** (0.955, 0.864) = **依然として負けている**。
   人気ベースライン(0.835, 0.814)より上なだけで、市場より少しマシに負けているに過ぎない。
4. 唯一 両OOS期間で>1.0 の「障害・長距離・良」も、**n=95 / n=43** と極小。
   2026は勝率4.65%×43レース = **的中2本**で回収率1.18。平均約25倍の大穴2本を拾っただけ。
   valid 4.32 → test 1.64 → 2026 1.18 と単調に減衰しており、真値は1未満に収束すると読むのが自然。
5. **最重要**: 勝率・複勝率 (低分散で信頼できる指標) では **全粒度・全セグメントで採用ゼロ**。
   本物の条件別シグナルがあるなら的中率にも現れるはずで、現れていない。

## 結論 (正直に)

- **条件別に重みを変えても、◎の的中率は市場(人気)を上回らない。** これは 119,069候補 ×
  全粒度 × 全条件で確認した、信頼できる結論 (低分散指標での明確な否定)。
- **回収率での「勝ち」は大穴くじの当たり外れであり、再現しない。** 採用3件は偽陽性
  (期待偽陽性35.4に対し3件、かつ内訳が上記のとおり)。**これを信じて賭けてはいけない。**
- ユーザー例の粒度 (場×芝ダ×距離×馬場) では、そもそもデータが薄く (中央値17レース/6年)
  採用ゼロ。専用モデルを作る根拠が無い。

## 手法上の反省と改善 (次にやるべきこと)

1. **回収率の点推定で採否を決めるのは危険**。ヘビーテールなので **bootstrap 信頼区間** を必須にし、
   下限が1.0を超えない候補は採用しない仕組みにすべき (今回の3件は下限が確実に1未満)。
2. **的中率の下限制約**を課す (例: ◎の勝率が人気の半分未満なら「大穴くじ」として除外)。
3 **未検証で残る領域**: 他券種 (複勝/ワイド/馬連/3連複)、確率キャリブレーション、
   ケリー等の資金配分。単勝フラットベット以外は未検証。
