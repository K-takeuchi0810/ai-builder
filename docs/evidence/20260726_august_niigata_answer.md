# 証跡: 「8月 × 新潟芝1800m良」の重み探索 実測結果 (2026-07-26)

ユーザーの例そのものを、月粒度・疎な重み・信頼区間つきで検証した結果。
生データ: `20260726_august_niigata_focused.json`。候補 **30,000通り**、
期間: train 2021-22 / valid 2023 / **test 2024** / **final 2025**（全て完全な年）。

## 結果: 採用 0 件

### 目的=勝率 (最も惜しい候補・重みは疎に2個だけ)

選ばれた重み: `agg_avg_final3f(直近3走・同距離同馬場)` = -0.5、`popularity` = +0.5

| 期間 | n | ◎勝率 | 人気の勝率 |
|---|---|---|---|
| train | 9 | 22.2% | — |
| valid | 10 | **70.0%** ← 探索で選ばれた根拠 | — |
| **test (2024)** | 12 | **41.7%** | 33.3% |
| **final (2025)** | 12 | **25.0%** | 25.0% |

- 95%信頼区間: test **[19.3%, 68.1%]** / final **[8.9%, 53.2%]**
- 判定: **不採用**。test では人気を上回るが CI下限(19.3%)が人気(33.3%)を下回り、
  final では人気と同じ25%で**再現しない**。
- **12レースでの41.7%対33.3%は「5勝対4勝」= 1レース差**。統計的に無意味。

### 目的=複勝率 (非ゼロ重み99個 = パラメータ過多)
valid 90% → **test 66.7%** (人気83.3%より低い) → final 58.3%。一貫性なし。

### 目的=回収率 (非ゼロ重み95個)
valid **3.23** → **test 0.108** (壊滅) → final 0.5。CI test **[0, 0.325]**。完全崩壊。

## 結論

- **この粒度では検証が原理的に成立しない。** 各期間9〜12レースでは、1レースの差が
  勝率8ポイントに相当し、どの重み付けが良いかを識別できない (CI幅が19%〜68%等)。
- 30,000通りの重みを試せば valid で勝率70%・回収率3.23 の「素晴らしい設定」は必ず見つかるが、
  それは10レースのノイズに合わせただけで、test/final では消える (実測済み)。
- これは検証手法の不足ではなく **データ量の物理的限界**。8月・新潟・芝1800m・良は
  年間約7レースしか存在しない。
