# 証跡: win_odds の単位・データ被覆 (2026-07-21 調査)

バリューベット (EV = 推定確率 × オッズ) 実装の前提となる実データ調査。read-only。
生ログ: `20260721_odds_units_and_coverage.raw.txt`（本ファイルはその解釈と決定）。

## 確定事実

1. **win_odds の単位 = 10進オッズ × 10**
   勝ち馬 (confirmed_order=1) の `tan_payout1 / win_odds` が **全8標本で厳密に 10.00**。
   `tan_payout` は 100円賭けあたりの払戻円 = 10進オッズ × 100。よって:
   - **10進オッズ = win_odds ÷ 10**（例: win_odds=42 → 4.2倍 → 100円が420円）
   - **市場推定勝率(implied) = 1 / 10進オッズ = 10 / win_odds**（オーバーラウンド込み）

2. **オッズ完備の実用期間 = 2021〜2025（＋2026途中）**
   | 年 | JRA確定レース数 | win_odds 有効率 |
   |---|---|---|
   | 2021 | 3,465 | 100% |
   | 2022 | 3,460 | 100% |
   | 2023 | 3,459 | 100% |
   | 2024 | 3,460 | 100% |
   | 2025 | 3,461 | 100% |
   | 2026 | 1,939 (7月時点) | 100% |
   - 2020 以前: レースは存在するが win_odds 欠損が多い（1986-1992 は約50%欠損、1993-2019 はほぼ空、2020 は847レース・欠損47.7%）。
   - **→ バリューベット検証は 2021 以降のみ使用**。それ以前は EV 計算不能なため除外。

## これを踏まえた設計決定

- **オッズ変換**: `decimal_odds = win_odds / 10`。win_odds が NULL/0 の馬・レースは EV 対象外。
- **検証期間**: 2021〜2025 を主軸にウォークフォワード（例: 〜2022訓練→2023検証, 〜2023→2024, 〜2024→2025）。2026 途中を最新 OOS として併用。
- **特徴量行列に per-horse で decimal_odds と win_popularity を保存**（EV 計算に必須）。MATRIX_VERSION を上げて再構築。
