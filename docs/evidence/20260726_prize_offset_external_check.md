# 証跡: 賞金オフセット366の外部照合と付加賞の扱い (2026-07-26)

`builder/prize.py` の本賞金オフセット (1-based 366, 8桁, 単位百円) を、**公表値との突合**で
検証した。従来の証拠 (5着まで単調減少・6着以降0%・非ゼロ率35.9%) はすべて内部整合性の証拠
だったため、独立した外部照合を追加する。

## 外部照合の結果 ✅

1. **1着賞金の絶対値が公表値と一致**
   - ジャパンカップ 2025: 索引 **500,000,000円** ↔ 公表 **1着賞金5億円**
   - 有馬記念: 公表でもジャパンカップと並ぶ **5億円**
   - 日本ダービー(東京優駿): 索引 **300,000,000円** ↔ 公表 **3億円**
2. **着順・馬名も一致** — ジャパンカップ2025 の 1着カランダガン / 2着マスカレードボール /
   3着ダノンデサイル は索引の馬番→馬名と一致。
3. **JRA の賞金比率と一致** — 1着100 : 2着40 : 3着26 : 4着15 : 5着10。
   ジャパンカップは 500/200/130/75/50 → 100:40:26:15:10 に厳密一致。

## 付加賞・褒賞金は **含まれない** (寄与分解の文言確定)

ジャパンカップ2025の勝ち馬カランダガンには、国際指定レース勝利による**褒賞金 300万米ドル
(約4億6500万円)** が上乗せされている。しかし索引の値は **きっちり 500,000,000 円**であり、
褒賞金を加えた額 (約9億6500万円) ではない。

同様に東京優駿は登録料由来の**付加賞**が付くレースだが、索引値は端数のない
**300,000,000 円**。

→ **オフセット366 は「本賞金」のみを指す。付加賞・褒賞金は含まない。**

寄与分解や UI では「**獲得本賞金**」と表記し、「賞金総額」「獲得賞金(付加賞込み)」とは
書かないこと。誤った言葉で説明すると参加者に誤解を与える。

## 結論

内部証拠 (5着ルール・比率・非ゼロ率) と外部証拠 (公表賞金額・馬名・比率) の両方が一致した。
オフセット366 = 本賞金 (単位百円) は**確定**とみなす。
